<Questions>

## Practical questions

### This is a client project.

That fits. Shpyrd can support the publication and updates of applications you build for clients.

### I already have hosting.

Try Shpyrd with one project and compare the workflow from the first deployment through the next update.

### Does rollback undo database migrations?

No. Rollback returns application code and configuration; it does not reverse migrations or saved data.
