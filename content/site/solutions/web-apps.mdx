<Questions>

## Practical questions

### Does my project need a web interface?

No. An API or a background worker is a project of its own.

### Can I run a SaaS on it?

Yes, as an application. Subscriptions, tenant isolation inside your app, and customer authorization are your app's to provide.

### Is there a scheduler for jobs?

Run your processing as a worker. Check the documentation for the workflows that are supported today.

</Questions>
