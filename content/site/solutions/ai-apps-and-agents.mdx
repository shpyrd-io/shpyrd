<Questions>

## Practical questions

### Does Shpyrd run the model?

No. Your application calls the external model service you choose; Shpyrd runs the application.

### Who defines how the agent behaves?

Your framework and your code. Shpyrd gives it a place to run, its configuration, and visibility into its operation.

### Can it run untrusted code from users?

Running arbitrary untrusted code is not part of what Shpyrd offers today.

</Questions>
