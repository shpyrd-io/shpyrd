<Questions>

## Questions people ask

### Does my app need AI features?

No. Any site or tool you made with an agent fits, whatever it does when it runs.

### Can my agent publish it for me?

Yes, through the Shpyrd CLI. The workspace MCP connection lets your agent inspect the project, its logs, and metrics.

### Can I import a project from an online builder?

Bring the project's code. Shpyrd publishes and runs it; it does not import a builder's own project format.
