## Why it just works

### Ask your agent

Claude Code, Cursor or Codex can deploy for you. Tell it: "Publish this app."

### No server to set up

We detect what your app is built with and build it. No Docker needed.

### From anywhere

A folder, a GitHub repository, or a container image if you already have one.

### Every version saved

Each deploy is a release you can look back at and return to.

### For developers too

The same deploy from the CLI and the API, for scripts and CI.

<Questions>

## Practical questions

### Do I need Docker or a config file?

Usually not: we detect most apps and build them. If yours needs settings, the guide shows how.

### Can my AI agent deploy for me?

Yes. Once you sign in, your agent can publish and update the app for you.

### What if a new version breaks something?

Go back to the previous version in one step, from the CLI or by asking your agent.

### Can I use my own domain?

Yes. Every app gets an address, and you can point your domain, such as app.yourapp.com, to it.

</Questions>
