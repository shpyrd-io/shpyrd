---
title: "Dedicated addresses for workspaces and apps"
description: "Workspaces use shpyrd.cloud and apps use shpyrd.app."
date: "2026-10-05"
type: improvement
draft: false
---

Cloud workspaces use `<workspace>.shpyrd.cloud`, while apps use `<workspace>-<app>.shpyrd.app`. Workspace address changes can retain the previous addresses as redirects for a transition period, helping existing links keep working.
