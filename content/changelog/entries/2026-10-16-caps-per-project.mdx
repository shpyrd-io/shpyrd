---
title: "Caps per project"
description: "A workspace administrator can hold one project's block storage below the workspace's ceiling."
date: "2026-10-16"
type: feature
draft: false
---

Workspace administrators can set a block storage cap on a project, below the workspace's own, from the General page. A project's Overview shows what it holds against the cap that applies to it, and a disk or database that would pass it is refused with the numbers.
