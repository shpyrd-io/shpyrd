description: "Use JSON output, jq filters, and file-based configuration inputs."
date: "2026-10-01"

draft: false
---

CLI commands that return data support `--json` and `--jq`, making their output easier to use in scripts and agent workflows. Configuration commands also accept file inputs, reducing the need to assemble long command lines. Interactive commands and raw log output keep their dedicated behavior.
