<Lead>

The roadmap is the list of open issues in the [shpyrd repository](https://github.com/shpyrd-io/shpyrd/issues): every proposal and every known gap is an issue labelled `enhancement`, with the design in its text and the discussion underneath. What is done is in the rest of these docs. Priorities move with the feedback in the issues.

</Lead>

- [Proposals and improvements](https://github.com/shpyrd-io/shpyrd/issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement): what is decided or proposed, waiting for someone to pick it up.
- [Everything open](https://github.com/shpyrd-io/shpyrd/issues): bugs included.
- [Pull requests](https://github.com/shpyrd-io/shpyrd/pulls): what is being built now.

To propose a change, open an issue that states the problem and the shape of the change, and discuss it there; the pull request that builds it refers to the issue. Until 2026-10-28 design changes were RFCs kept in the repository; each one with pending work became an issue that day, and their text stays in the repository's history.
